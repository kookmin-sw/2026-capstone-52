# 서비스 가이드

이음 서비스는 학습 자료 업로드, 학습 수준 진단, 맞춤 AI 튜터링, 지식 그래프 탐색을 하나의 학습 흐름으로 연결합니다.

## 하위 문서

- [사용자 흐름]({{ '/documents/service/user-flow/' | relative_url }})
- [주요 기능]({{ '/documents/service/features/' | relative_url }})

## 서비스 흐름

1. 사용자가 프로젝트를 만들고 학습 자료를 업로드합니다.
2. 시스템이 자료를 분석하고 핵심 개념을 추출합니다.
3. 사용자는 진단 질문을 통해 현재 이해도를 확인합니다.
4. AI 튜터가 사용자 수준에 맞춘 설명을 제공합니다.
5. 누적된 개념은 지식 그래프로 시각화됩니다.
